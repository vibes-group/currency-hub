# Currency Hub

Mobile-first currency tracking PWA prototype built with React, Vite, React Router, Tailwind CSS, shadcn-style primitives, and FSD-inspired structure.

## Scripts

```bash
bun run dev
bun run build
bun run preview
bun run lint
```

The Vite dev server opens at `http://localhost:5173`.

## Routes

- `/ru` and `/en` - home screen
- `/ru/list` and `/en/list` - fxapi rates list
- `/ru/demo` and `/en/demo` - UI primitives demo
